Nahlam / English typography study

Study only. Inter is fixed. No images. No production changes.

Recommended standard / v1

One family. Three weights. Six clear text roles.

Inter remains the English typeface. The study keeps the current visual character while turning the page’s individual font values into a small, reusable system. Bold is reserved for hierarchy, not general emphasis.

The recommendation

Use Inter 400 for reading, 700 for structural emphasis, and 800 only for identity, the main display statement, and short status labels. Use a fluid scale so text grows gradually between mobile and desktop without losing browser zoom support.

What becomes bold

The wordmark, the main display statement, short status labels, section titles, and words carrying genuine meaning. Ordinary explanatory sentences remain 400.

What stays regular

Introductions, body paragraphs, explanations, and callouts. Color and spacing should distinguish these before adding weight.

Reading width

Keep English body text between roughly 45 and 70 characters per line. The lead paragraph is capped at about 61 characters for a calm return sweep.

Uppercase

Use uppercase only for short labels and identity. Add tracking there, but never use tracked uppercase for paragraphs or long headings.

Accessibility

Body text never drops below 16px. Sizes use rem-based fluid values, allowing browser zoom. Existing ink, green, and muted text colors meet WCAG AA on the paper background.

Restraint

Use no more than three obvious emphasis levels in one view. If everything is bold, hierarchy disappears.
